# Sarkar RB

A three-weight Kurdish typeface by **Sarkar Salar**. 562 glyphs, kerned in every
weight. Version 1.001.

## Weights

Light · Regular · Bold

## Formats

| | |
| --- | --- |
| `TTF/` | desktop installation |
| `WEB/WOFF2/` | web |
| `WEB/WOFF/` | web, older browsers |

No OTF: the typeface is distributed as TrueType only, and nothing here converts
outlines from one flavour to another.

## Coverage

Complete Central Kurdish (Sorani) alphabet, including ڕ ڵ ۆ ێ ڤ ھ ە, with
initial, medial and final forms for every joining letter. Arabic-Indic digits and
Latin digits. Contextual alternates, localised forms, ligatures, fractions,
numerators and denominators, mark and mark-to-mark positioning.

ھ (U+06BE) is mapped to the font's own ه, whose initial and medial forms are the
same letter shapes; the isolated and final forms are the narrower heh.

**Sorani only.** ş and Ş are not included, so Kurmanji cannot be set in Sarkar RB
— use Lenos or K24 for that.
