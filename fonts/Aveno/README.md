# Aveno

Aveno is a Kurdish typeface distributed as part of the Kurdish Font Library.

## Family

- Regular
- Bold

## Formats

- TrueType (TTF)
- OpenType (OTF)
- Web fonts (WOFF2)

## Language Support

Aveno supports Kurdish written in the Arabic script and includes Latin characters for multilingual use.
