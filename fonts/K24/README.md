# K24

A two-weight Kurdish display typeface by **RTLtype**, originally released as
K24 Kurdish. Version 1.001.

> The original font is marked **"All rights reserved"** by its author. See
> [LICENSE.md](LICENSE.md).

## Weights

Light · Bold

There is no Regular.

## Formats

| | |
| --- | --- |
| `OTF/` | print and publishing |
| `TTF/` | desktop installation |
| `WEB/WOFF2/` | web |
| `WEB/WOFF/` | web, older browsers |

## Coverage

Complete Central Kurdish (Sorani) alphabet, including ڕ ڵ ۆ ێ ڤ ھ ە, with
initial, medial and final forms for every joining letter. Complete Kurmanji
(Hawar) Latin alphabet. Arabic-Indic and Extended Arabic-Indic digits.

Not included: U+066B (٫ decimal separator) and U+066C (٬ thousands separator).

Neither weight has kerning, so expect to adjust tracking by hand at display
sizes. Bold also carries 28 Latin codepoints that Light lacks; Kurdish coverage
is complete in both.
